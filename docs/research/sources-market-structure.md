## Accessed community evidence

**M9 — pytse-client**, third-party open-source wrapper, not an exchange rulebook or independent market-data authority:

- [Pinned README](https://github.com/Glyphack/pytse-client/blob/56f5af6a7bca8188debc0badbe4da2ae0deb1d02/README.md) — raw bytes fetched successfully. Claims adjusted/unadjusted histories, client-type histories, order-book history, five best levels and shareholder history. `adjust=True` is documented separately from `adj_close` (“قیمت پایانی”). Client counts are described as “تعداد معاملات خرید حقیقی” etc.; that imprecision is a reason to verify the upstream definition, not proof of distinct participants.
- [Pinned extractor source](https://github.com/Glyphack/pytse-client/blob/56f5af6a7bca8188debc0badbe4da2ae0deb1d02/pytse_client/ticker/api_extractors.py) — raw bytes fetched successfully. `get_instrument_info` directly maps `cIsin`, `instrumentID`, `flow`, `baseVol`, and board labels. `TradeSummary` keeps count and volume separate, and legacy text parsers use positional fields. Wrapper behavior must not be mistaken for an official data specification.
- [GitHub tree response used to pin revision](https://api.github.com/repos/Glyphack/pytse-client/git/trees/master?recursive=1) — HTTP 200, root SHA `56f5af6a7bca8188debc0badbe4da2ae0deb1d02`. URLs above use this fetched revision so later branch changes do not silently change the cited interpretation. No package was installed and no wrapper code executed.
