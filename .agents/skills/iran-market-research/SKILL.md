# Iranian market research

A formula can be established while its usefulness for predicting Iranian returns remains untested. Identify both evidence levels.

## Reference workflow

1. Read the project's dataset inventory and identify the exact observed universe, reporting frequency, units and availability timestamps.
2. Form a falsifiable question: explanatory variable, outcome, eligible instruments, decision time, holding horizon and null benchmark. A descriptive question need not have a trading outcome.
3. Inspect a primary source and, where available, an independent implementation. Prefer operative SEO/CMR resolutions and TSE/IFB notices for rules, official-host TSETMC data for observed fields, CODAL for company publications, and original papers for empirical methods.
4. Record exact URL, author/publisher, title, retrieval date, effective/study dates, universe, accessed content level (full text, abstract, metadata or shell), and contradictory evidence. A live endpoint observation establishes one response, not a supported historical API or universal rule.
5. Compare study assumptions with Iran: instrument boards, limits, halts, auctions, liquidity, inflation, publication lags, market makers, feasible shorting and exit constraints.
6. Produce the assessment below and update the catalog before proposing a calculation.

## Assessment record

| Field | Required content |
|---|---|
| Method/purpose | Concrete analytical question |
| Rationale/evidence | Identity, established statistic, empirical association, informal heuristic or untested hypothesis |
| Definition | Exact formula/algorithm and denominators |
| Inputs | Observed fields and scope; missing fields and enrichment sources |
| Timing | Event/session date, publication/version availability and earliest usable decision |
| Limitations | False positives, competing explanations, selection and execution assumptions |
| Evaluation | Numerical checks, descriptive stability, or pre-registered out-of-sample outcomes |
| Delivery | Complexity, priority, citations and next gate |

## Domain example

“Repeated institutional net purchases imply accumulation” is a research hypothesis. Daily files can establish repeated institutional net buying when four value amounts reconcile. They do not identify beneficial ownership, market-maker intent, or future excess returns. Missing sessions are unknown observations; participant counts and adjusted returns require separate evidence.

## Common mistakes

- Treating a Persian blog or a code wrapper as operative exchange law.
- Quoting a price-limit percentage without board, instrument and effective date.
- Using a DOI search result as if the paper's findings were read.
- Calling a familiar indicator predictive without a dated, executable evaluation.

## Output

A source register entry and catalog card with an explicit supported/conditional/blocked status. Numerical results must come from versioned code and traceable inputs.
